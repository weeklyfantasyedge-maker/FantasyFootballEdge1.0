# Fantasy Football Edge — V1

A first-pass Next.js website for the Fantasy Football Edge brand.

## Run locally

1. Install Node.js 20+.
2. Open Terminal in this folder.
3. Run:
   `npm install`
4. Then:
   `npm run dev`
5. Open:
   `http://localhost:3000`

## Deploy

Push this folder to GitHub, then import the repository into Vercel.

## V1 notes

- The intake form is a front-end prototype. It does not submit anywhere yet.
- The Edge Board uses sample data.
- Newsletter form is visual only until an email provider is selected.
- Legal pages and real data integrations should be added before public launch.
